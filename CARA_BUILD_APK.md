# Cara Build APK Native (HEEX.) Lewat GitHub Actions (Gratis & Otomatis)

1. Buat repository baru di GitHub kamu (misal: `argo-music-apk`).
2. Ekstrak seluruh isi file ZIP ini lalu upload/push ke repository tersebut (pastikan folder `.github/workflows/build_apk.yml`, `lib/main.dart`, `pubspec.yaml`, dan `android/` ikut ter-upload).
3. Buka tab **Actions** di repository GitHub kamu.
4. Klik workflow **Build HEX Android APK** -> klik **Run workflow**.
5. Tunggu sekitar 3–4 menit sampai centang hijau, lalu unduh file **`HexApp-Android-Release-APK`** di bagian **Artifacts** di bawah halaman Actions.
